# Experimental setup

The experiments use the ~250,000-product sample of the Clothing, Shoes and Jewelry metadata (data version `data/sample.parquet (249,762 rows, make_sample.py 2219c1e)`, seed 42), not the full category. Task A uses the 90,979 listings with a composition string and all ten classes (each has at least `MIN_CLASS_ROWS = 20` listings); Task B uses listings with at least 5 ratings (`MIN_RATING_NUMBER = 5`), which drops 30.7% of rated products (our arithmetic). The pilot is an earlier run on the first 10,000 records (nine classes), quoted only where labeled as pilot.

`src/make_sample.py` assigns each listing once to the training or test set by hashing the product identifier with seed 42 (about 20% to test), and all tasks share that assignment: 72,661 training and 18,318 test listings for Task A, and 138,355 and 34,836 for Task B after the filter. All models are fitted on the training set only, including the TF-IDF vocabulary, and each is scored once on the test set, without tuning. Task C streams the category's review file once, keeping at most the first 20 reviews of each sample product (866,008 reviews); 15,397 products have at least three polar material sentences and so receive a target (12,304 training and 3,093 test products), modeled without sample weights so that it can be compared with the star average on the same test products.

For Tasks B and C, no feature comes from the product's own ratings or reviews. Task A is scored by macro-F1, so every material counts equally, and Tasks B and C by RMSE and MAE on the unweighted test set, all through `src/evaluate.py`. Confidence intervals are 95% percentile-bootstrap intervals from the saved test-set predictions (1,000 resamples, seed 42; `python analysis/ci_from_predictions.py`), and paired difference intervals use the same resamples for both models. The CPU runs (steps in Appendix A) took 1,537 s for Task A (including the calibrated demo model), 1,265 s for Task B, and 486 s for Task C from its review cache on a Windows 11 laptop with 16 GB of RAM, and DistilBERT took 1,719.8 s for both settings on one NVIDIA GeForce RTX 5090 Laptop GPU.

We departed from the submitted proposal in three ways. We did not run its gradient-boosted trees over text and structured features for material classification; DistilBERT is the nonlinear text model we compared instead. We used one fixed hashed (not stratified) train/test split with bootstrap and paired-difference intervals, plus a 20% validation split inside training for DistilBERT's epoch choice, instead of the proposed cross-validation. We dropped the proposal's review aggregates as rating features because they derive from the item's own reviews and leak the target, and added Task C after instructor feedback.

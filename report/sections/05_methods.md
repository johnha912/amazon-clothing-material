# Proposed method

For Task A each cleaned listing becomes a TF-IDF vector over word unigrams and bigrams (terms found in at least two listings, up to 60,000), with the weight of term $t$ in listing $d$

$$w_{t,d} = \bigl(1 + \log \text{tf}_{t,d}\bigr)\cdot\left(\log\frac{1 + N}{1 + \text{df}_t} + 1\right),$$

where $N$ is the number of training listings and $\text{df}_t$ is how many contain $t$; each vector is scaled to unit length. The inverse document frequency lowers words found in nearly every listing ("size", "color") while raising rare ones ("linen"), and bigrams let the model see phrases such as "genuine leather" as units (Wang and Manning, 2012, found bigrams a mixed bag in topical classification).

Logistic regression turns the vector into class probabilities with a softmax and minimizes a class-weighted log loss with an $L_2$ penalty ($C = 1$). The class weight $c_k = n / (K n_k)$ makes each listing of a rare class count more, so polyester and cotton do not drown out the other fibers; NLP models "tend to perform poorly on less frequent classes" (Henning et al., 2023). Its probabilities give the demo a confidence score, but it cannot tell "not cotton" from "cotton". The linear SVM uses the same features and class weights but learns, per class, the widest-margin hyperplane against the rest with a squared hinge loss, so it focuses on borderline listings (objectives in Appendix B); both train in seconds on a CPU.

DistilBERT (Sanh et al., 2019) is the contrast: a 6-layer transformer that reads each word in context. We feed it the first 256 word pieces of the same cleaned text, add a small classification head, and fine-tune every weight (settings in Appendix B) with the plain loss or the class weight $c_k$. The number of epochs (at most 3) is chosen on a validation set, 20% of the training listings held out with seed 42, never on the test set, and the report leads with the setting that has the higher validation macro-F1, a rule set before any test score existed.

For Task B the inputs are the listing features of the data analysis, with the number of ratings $n_i$ used only for the row filter and as the sample weight $s_i = \log(1 + n_i)$. The baseline predicts the weighted training mean for every product. The random forest averages 300 regression trees, each grown to full depth on a bootstrap sample. XGBoost instead adds shallow trees one at a time, each fitted to the remaining weighted squared error with a penalty on its size (400 trees of depth at most 6, learning rate 0.06, 90% row and column subsampling). All settings were fixed before seeing test results, not tuned.

Task C scores the review sentences that name a fabric or a feel word that only describes fabric (soft, scratchy, itchy) with a transparent lexicon: positive and negative fabric terms count $+1$ and $-1$, a nearby negator flips a term's sign, and the sign of the sum is the polarity, with ties dropped. A product's material sentiment is the share of its polar material sentences that are positive, kept only when it has at least three. We check the lexicon against the review's own star rating and a pretrained sentiment model (Results). We predict the score from the Task B features with the mean baseline and XGBoost; review text and stars build the target only.

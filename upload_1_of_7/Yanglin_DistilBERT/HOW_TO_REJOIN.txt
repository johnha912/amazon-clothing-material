These 12 parts (.001 to .012) are the trained DistilBERT weights file
model.safetensors (267,854,100 bytes), split because GitHub's web upload
accepts at most 25 MB per file.

1. Download all 12 parts into one folder.

2. Rejoin them:

   Windows (Command Prompt, in that folder):
     copy /b model.safetensors.001+model.safetensors.002+model.safetensors.003+model.safetensors.004+model.safetensors.005+model.safetensors.006+model.safetensors.007+model.safetensors.008+model.safetensors.009+model.safetensors.010+model.safetensors.011+model.safetensors.012 model.safetensors

     Or with 7-Zip: right-click model.safetensors.001 > 7-Zip > Combine files.

   Mac / Linux:
     cat model.safetensors.0* > model.safetensors

3. Unzip Yanglin_DistilBERT_code_docs_results_2026-11-02.zip, then put model.safetensors here:
     project/models/material_bert/final/model.safetensors

Check (optional): model.safetensors SHA-256 should be
  6cc627a580abef0d2011cb59a97d8eba059debb5d013a3a802e6cca5563a307f
(the same value is listed in SHA256SUMS.txt inside the code zip)
